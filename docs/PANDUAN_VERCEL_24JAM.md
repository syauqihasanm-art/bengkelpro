# Panduan Deployment Vercel 24 Jam Non-Stop (Gratis Selamanya)

Aplikasi **BengkelPro** siap di-deploy ke **Vercel Cloud**. Karena kode proyek sudah 100% tersinkronisasi di GitHub Anda (`https://github.com/syauqihasanm-art/bengkelpro`), proses deployment ke Vercel hanya membutuhkan waktu **1 menit** tanpa perlu konfigurasi teknis yang rumit.

---

## Mengapa Vercel?
1. **Dibuat oleh Tim Pembuat Next.js**: Vercel adalah rumah dari Next.js, sehingga seluruh 53 halaman, modal interaktif, dan API langsung berjalan 100% tanpa risiko error adapter.
2. **Online 24 Jam Non-Stop**: Berjalan di cloud serverless Vercel di seluruh dunia. **Meskipun laptop Anda dimatikan atau internet rumah putus, website tetap aktif 24 jam.**
3. **100% Gratis Selamanya**: Paket Vercel Hobby gratis tanpa batas waktu dan tanpa perlu kartu kredit.
4. **Domain HTTPS Resmi**: Anda langsung mendapatkan domain SSL aman seperti `https://bengkelpro.vercel.app`.

---

## Langkah 1-Klik Deploy ke Vercel:

1. **Buka Halaman Vercel**:
   Kunjungi tautan resmi: 👉 [vercel.com/new](https://vercel.com/new)
2. **Login dengan Akun GitHub**:
   Pilih tombol **"Continue with GitHub"** dan izinkan akses ke akun GitHub Anda (`syauqihasanm-art`).
3. **Pilih Proyek BengkelPro**:
   Di daftar *"Import Git Repository"*, cari **`bengkelpro`** lalu klik tombol **"Import"**.
4. **Pengaturan Proyek (Biarkan Default)**:
   * **Project Name**: `bengkelpro` (atau nama unik sesuai keinginan Anda).
   * **Framework Preset**: `Next.js` (otomatis terdeteksi).
   * **Root Directory**: `./` (biarkan kosong / default).
5. **Klik "Deploy"**:
   Klik tombol hitam besar bertuliskan **Deploy**.
6. **Selesai!**:
   Tunggu sekitar 45 detik. Setelah selesai, layar akan menampilkan konfeti dan tautan domain permanen Anda (contoh: `https://bengkelpro.vercel.app` atau `https://bengkelpro-syauqihasanm-arts-projects.vercel.app`).

---

Buka domain Vercel yang Anda dapatkan di browser HP (Chrome, Safari, dll).
Semua fitur (Owner, Admin Kasir, Montir, Pelanggan, Super Admin) dapat diklik secara interaktif dan berjalan *end-to-end*.
